# Seestar ALP homelab image

Builds the upstream [smart-underworld/seestar_alp](https://github.com/smart-underworld/seestar_alp) Docker image for the homelab.

The build is pinned to upstream commit `2f7747f807e8d361c7bab206f0143720354acd6d` (post-`v3.2.2`, including the firmware 7.18+ authentication fixes) and publishes immutable `sha-<wrapper-commit>` tags to GHCR.
