# Seestar ALP homelab image

Builds the upstream [smart-underworld/seestar_alp](https://github.com/smart-underworld/seestar_alp) Docker image for the homelab.

The build is pinned to upstream release `v3.2.2` commit `b007037d346714cd805775ded6f3402d2c0a5194` and publishes immutable `sha-<wrapper-commit>` tags to GHCR.
